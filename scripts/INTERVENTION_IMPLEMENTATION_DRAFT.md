# B/C 干预实施清单（烟测期间草稿）

本文件只列实施与验收步骤，不是已经执行的干预，也不是医学真值判定。等待当前 15 组真实烟测完成后，再同步 `EXPERIMENT_PLAN.md`、代码和测试；更改会产生新的运行指纹与输出目录。

## 先固定题集与分配

1. MedQA 两次普通组共 60 个主持者答案，按既定 `≥54` 门槛决定后续临床题为 30 MedQA 还是 20 MedXpertQA Text；PubMedQA 仍为 20 题。保存切换决定、题目文件 SHA-256 与来源 manifest。不可把两个临床题集合并抽样。
2. 在最终当前临床题中无放回抽 15、PubMedQA 中无放回抽 10，B/C 共用同一 25 题。使用固定种子、独立分层随机流，写 `intervention_selection.json`：题目 ID、题集、种子、抽样框文件哈希、抽中 ID、时间。此选择在分析干预结果前冻结，不能按模型表现筛题。
3. 首轮 B 条件为 `base`、`literal3`、`paraphrase3`。保留 `literal5`、`paraphrase5` 实现，但只能用显式后续选项启动，且新输出目录/指纹。C 仍为三条件。`assignments.jsonl`、实际运行循环和报告三处必须使用同一个已冻结条件列表。

## 素材与预检

1. 对最终题集先固定同一语料、MedCPT 索引与每题初始 top-6 检索快照。保存语料/索引哈希、模型 revision、返回的 `chunk_id`。`b_target_id` 必须属于该题 top-6，且真实原文可从语料按 ID 唯一找回；空快照题需提前标记，不能运行到中途才失败。
2. 研究者在看干预结果前为每题填 `b_target_id`、对应的目标选项键、两条 `paraphrase3` 转述。转述必须保持原文命题、人群、条件及方向，不能增加新的医学事实；保留原文哈希、转述文本哈希、人工核对记录。可选 5 次暴露才需要四条转述。
3. C 证据扰动、错误选项与消息模板由研究者预先定稿，记录来源、拟改变的命题、人工核对状态。模型草稿不能自动成为“医学错误”金标；未核验的断言只能标为人工扰动／银标，评价仍使用原数据集题目标签。`c_message_text` 应有 `{wrong_label}` 或 `{wrong_text}`，错误选项须为合法且非金标；金标与扰动标签绝不发给被测模型。
4. 在任何付费模型调用前，一次性检查 25 行规格：无重复/缺失/额外题号；目标片段在固定快照；目标选项合法；转述数量与非空；C 文本非空；错误选项非金标；随机接收者/发言者/轮次已按题和 repeat 冻结。将规格 SHA-256、审核状态和条件列表写入运行配置。检查调用请求仅有可见证据/消息，不含金标、`derived_from`、生成谱系或人工错误标签。
5. 运行后核对原文副本实际总暴露 3 次（原文＋2 副本）；改写副本有不同 `chunk_id`、审计图 `derived_from` 指向同一目标；C 证据侧在 R0 前暴露，消息侧和重复转述沿用未扰动 R0；每个注入位置与可见消息都有审计记录。

## 代码改动点与验收测试

- `interventions.py`：`subset25` 替换 `subset20`；将首轮 B 默认集合和可选 5 次集合分开。保留完整的 `b_evidence` 实现，避免删掉后续可选条件。
- `cli.py`：先冻结/预检抽样与所有素材，再创建分配和调用模型；同一条件列表驱动分配与运行。拒绝重复规格 ID、缺失 `target_answer`、不在初始快照的 `b_target_id`。随机 C 配置预生成并入审计 manifest。更新指纹字段，旧输出目录不可混用。
- `README.md` 与 `EXPERIMENT_PLAN.md`：摘要、B、C、示例规格同步为 25 题和首轮 3 个 B 条件；修正文中误写的重复标点。
- 测试：30 临床＋20 PQA 与 20 临床＋20 PQA 两种最终题集均抽中精确 15＋10；固定种子可重放，换题集产生新 manifest；默认仅 3 个 B 变体，显式选项才出现 5 次变体；25 题的 B/C ID 完全一致。对无目标、重复/缺行、空转述、错选项等在首个模型调用前失败；检验副本数量/谱系、C 在 R0 前后位置、金标/隐藏标签不可见；CLI mock 完成三组两次，评价分母等于全部分配。若最终为 50 题且 B/C 同跑，分配总数为 1200；若 40 题则为 1140（每题自然组 3×2，25 题另有 6 个变体×3×2）。这些仅是软件分配数，不是独立患者样本数。
