# 模型对话查看器

启动本地只读网页：

```powershell
& 'C:\Users\Administrator\miniconda3\envs\med-consensus\python.exe' scripts/log_viewer.py
```

打开 http://127.0.0.1:8765 。仅使用 Python 标准库，不需要 API 密钥，不会调用模型，也不会修改实验日志。

1. 输入题号，例如 `803`，或完整/部分 `run_id`。
2. 选择“全部批次”跨目录搜索，或选择某批次。数字题号精确匹配，避免把 `8030` 混作 `803`。
3. 左侧选择一次实验。不同批次、方法和 repeat 分别展示。
4. 沿调用时间线选择招募、独立作答、讨论、主持人汇总或格式修复。
5. 右侧阅读发送内容、模型返回；展开系统提示词和原始 JSON 可查看全部字段。

支持按调用类型或异常筛选，复制单次对话、复制 run_id，以及导出本题全部调用为 JSON。运行中的实验可点击“刷新日志”，不需要重新启动服务。

选择题目后，点击 **证据图谱**：

- **过程总览**：按独立作答、各轮讨论、主持人和最终结果排列，查看各位专家选择了什么。点击卡片阅读完整观点。
- **追溯最终答案**：展开主持人的观点和其引用的来源；也可选择任意节点，再点击“以此为中心追溯”。支持向前 2 层、4 层或全部来源。
- **点击具体观点**：查看原文、针对的选项、支持/反对/限制等立场、适用条件、原始提出者以及前后引用关系。文献节点可以打开保存的来源链接。
- **查看对应模型对话**：跳回已匹配的实际请求和返回。只有能唯一对应调用时才显示此按钮。
- **同时显示“当时可见”**：额外显示输入暴露关系。默认图中保留题目输入和明确引用；看见材料不代表使用了材料。
- 支持缩放、拖动空白区域、滚动查看和导出图谱 JSON。图内卡片只显示摘要，下方保留完整原文。

图谱优先读取同目录 `events.jsonl`。同一 run 的多个 `attempt_id` 通过“执行记录”选择，分别构图；语义合并消息保留当时的版本，后续加入的观点不会倒灌到早先的引用。没有执行编号时会提示无法区分重试。同一 run 中没有对应最终结果的执行不会显示成功答案。

旧日志没有 turn 事件时，仅从已保存的请求与返回恢复能确认的字段，并提示未验证回答格式；不通过文本相似度猜测 `ref` 的作者。未找到来源映射的引用会保留为未解析来源。无 RAG 的实验不生成文献节点，仍能追溯专家讨论。

图中的线表示日志里的引用、当时可见、观点归属、展示映射及材料派生关系。**引用不保证文献真的支持观点，图谱也不是模型内部思考的记录。** 标准答案仅用于页面对照，不参与图谱来源或引用关系。此功能不调用模型、不修改主实验代码、提示词或原始数据。

直接查看第 803 题图谱：

http://127.0.0.1:8765/?q=803&batch=medqa_screen_output2000_full_oct11&view=graph

默认读取 `runs/` 直接子目录的 `calls.jsonl`。直接问答脚本将请求和返回保存在 `results.jsonl` 中，也会自动识别。只完成招募便中断的题目同样可查。结果状态来自同一目录的 `results.jsonl` 和 `failures.jsonl`。

`wire_request.messages` 是实际请求内容；旧日志缺少它时，页面明确标明仅展示程序提交的数据。返回以日志 `response` 为准，原文中的英语不自动翻译。标准答案单独用于对照，不会被加入请求展示。

一些历史 `calls.jsonl` 没有 `attempt_id`。页面保留同一 run_id 的全部原始调用顺序并提示这一限制，不根据成功结果猜测调用属于哪个 attempt；专家招募只匹配同题、同 repeat，并标明为共享准备调用。继续运行所继承的旧成功结果，需到其实际调用所在的原批次查看，或选择“全部批次”搜索。

服务只绑定 `127.0.0.1`，只提供固定静态文件和日志读取接口；不提供任意文件读取、模型调用或写入接口。凭据字段不会显示。题干、文献和模型文本按普通文字展示，不执行其中的 HTML。

自定义位置或端口：

```powershell
python scripts/log_viewer.py --runs runs --port 8766
```

按 `Ctrl+C` 停止前台启动的服务。后台启动时可根据 `runs/log_viewer/process.pid` 确认并停止查看器进程，不影响模型服务或实验。
